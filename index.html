JSON
Ver guía

Convertí las notas finales que pego al final de este mensaje en JSON válido para importar en Librarium. Devolvé únicamente el JSON, sin Markdown ni explicaciones. Conservá fielmente los textos, números y páginas; no inventes datos. Cada nota debe tener number (entero) y text (cadena). Incluí reference_page solo si la nota tiene una página de referencia en el texto principal; si no la tiene, omití ese campo. Incluí end_page solo si conocés la página donde aparece la nota. Usá read:false. Escapá comillas y saltos de línea para que sea JSON válido.

{
  "schema_version": 1,
  "book": {"title": "Título", "author": "Autor"},
  "notes": [
    {"number": 1, "reference_page": 12, "end_page": 245, "text": "Texto de la nota", "read": false},
    {"number": 2, "end_page": 246, "text": "Nota sin página de referencia", "read": false}
  ]
}

Ajustes de IA

Estas preferencias se guardan en este navegador y se aplican tanto a consultas por nota o cita como al análisis completo de cada libro.

¿Cómo consigo mi API key gratuita en 1 minuto?
  1. Entrá a Google AI Studio e iniciá sesión con tu cuenta de Google.
  2. Tocá Create API key (o Crear clave de API) y copiala.
  3. Pegala en el campo de arriba y tocá Guardar en este dispositivo.

La clave queda en el almacenamiento local de este navegador, sin cifrar; no se sube a Librarium, no se sincroniza ni se incluye en las copias de seguridad. Las consultas van directamente a Google, que recibe la clave y el contenido enviado. El historial de conversaciones puede sincronizarse con tu cuenta de Librarium si activaste la sincronización. Librarium no incluye una clave global: sin tu clave personal, las funciones de IA quedan desactivadas.

La lista se consulta directamente a Google con tu clave.
