JSON
Ver guía

Convertí las notas finales que pego al final de este mensaje en JSON válido para importar en Librarium. Devolvé únicamente el JSON, sin Markdown ni explicaciones. Conservá fielmente los textos, números y páginas; no inventes datos. Cada nota debe tener number (entero) y text (cadena). Incluí reference_page solo si la nota tiene una página de referencia en el texto principal; si no la tiene, omití ese campo. Incluí end_page solo si conocés la página donde aparece la nota. Usá read:false. Escapá comillas y saltos de línea para que sea JSON válido.

{
  "schema_version": 1,
  "book": {"title": "Título", "author": "Autor"},
  "notes": [
    {"number": 1, "reference_page": 12, "end_page": 245, "text": "Texto de la nota", "read": false},
    {"number": 2, "end_page": 246, "text": "Nota sin página de referencia", "read": false}
  ]
}
