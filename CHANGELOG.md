# Novedades de Librarium

Este registro resume los cambios para quienes usan Librarium, sin tecnicismos. Los primeros hitos son una reconstrucción del historial de Git: el proyecto no tenía versiones publicadas ni etiquetas de versión para cada parche, así que esos números sirven para ordenar los cambios y no representan lanzamientos históricos exactos. La versión actual del proyecto figura como `1.0.0`.

## "1.0.0" — 27 de noviembre de 2026 · Versión actual

### Se agregó
- Una frase clave al final de las respuestas completas de la IA, que se puede guardar dentro de la nota, anotación o cita de origen.
- La opción de guardar la respuesta completa como comentario secundario, o solo la frase clave como anotación.
- La opción de consultar y borrar frases y respuestas guardadas desde el elemento, además de encontrarlas con la búsqueda.

### Se mejoró
- Las frases guardadas se conservan en las copias de seguridad y se combinan al sincronizar dispositivos.
- La frase clave responde de forma directa e incluye los datos concretos que se preguntaron.

## "1.0.0" — 26 de noviembre de 2026 · Hito reconstruido

### Se agregó
- Una sección de novedades para consultar los cambios de Librarium.
- Comentarios dentro de cada libro para guardar ideas y conversar sobre ellas con la IA.
- Un control anti-spoilers activado por defecto, que toma como referencia la página de lectura.

### Se mejoró
- La búsqueda en la biblioteca y las herramientas para revisar y actualizar vínculos entre personajes.

### Se cambió
- La pestaña «Anotaciones» de cada libro ahora se llama «Comentarios»; «Fotografías» sigue disponible a su lado.

## "0.3.0" — 25 de noviembre de 2026 · Hito reconstruido

### Se agregó
- Fichas de personajes para cada libro, con vínculos familiares y de otros tipos.
- Una red visual de personajes que se puede explorar, animar y compartir.
- Ayudas de IA para completar fichas y revisar vínculos teniendo en cuenta el avance de lectura.

### Se mejoró
- El uso de la sección de personajes en pantallas pequeñas.

## "0.2.0" — 24 de noviembre de 2026 · Hito reconstruido

### Se agregó
- Un chat de pantalla completa para conversar con la IA sobre libros, notas, citas y anotaciones.
- Una lista de conversaciones anteriores con la IA.
- Citas favoritas, fotos tomadas desde la aplicación y opciones para reportar problemas o proponer mejoras.

### Se mejoró
- El chat puede continuar si una respuesta se interrumpe o si un modelo deja de responder.
- Los filtros de la biblioteca, la instalación en el celular y el guardado sin conexión.

## "0.1.0" — 23 de noviembre de 2026 · Inicio del proyecto · Hito reconstruido

### Se agregó
- Una biblioteca para organizar libros y seguir el progreso de lectura.
- Notas finales, anotaciones, fotografías y reseñas personales.
- Un diseño adaptable al celular, modo oscuro y la posibilidad de instalar Librarium como aplicación.
