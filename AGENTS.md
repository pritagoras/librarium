# Instrucciones del proyecto

- Cada vez que cambies una función visible o el comportamiento de Librarium, actualizá también `CHANGELOG.md` en el mismo cambio.
- Escribí las novedades en español simple, para las personas que usan la aplicación. Agrupalas como «Se agregó», «Se mejoró», «Se cambió» o «Se quitó»; evitá detalles internos y tecnicismos.
- Poné la versión entre comillas, la fecha y una marca si es una reconstrucción histórica. Para cambios nuevos, seguí la versión de `package.json` y agregá la entrada más reciente arriba.
- Si una versión nueva implica cambiar la versión del proyecto, mantené `package.json` y `CHANGELOG.md` sincronizados.
- No borres entradas anteriores. Si una versión histórica no se puede confirmar en Git, indicá que el hito es reconstruido en vez de presentarlo como un lanzamiento exacto.
- La sección Novedades de la aplicación se genera desde `CHANGELOG.md`; mantené ese archivo como fuente de verdad.
